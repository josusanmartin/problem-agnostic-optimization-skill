# Multi-Agent Portfolio

Use only when multi-agent mode is explicit and workers can test distinct mechanisms concurrently or independently or adversarially review high-risk claims. Keep it unloaded for solo work or one delegated edit.

## Parallelism Must Buy Overlap

Fix the shared contract and protected parent, start workers immediately, and keep the coordinator experimenting. If coordination costs more than candidate work, collapse to solo only when multi-agent mode is not contractual, and state the change.

Give each worker the contract, baseline, named parent, distinct mechanism/prediction, budget/kill, and output path. Before the first concrete return, share validated facts.

Set no fixed worker quota. Duplicate a family only for replication, independent derivation, or a separable implementation.

## Delegate Experiments, Not Narration

Use one compact return and active registry:

```text
family | owner | parent | mechanism/prediction | budget/kill | artifact/proof/screen/blocker | next/reopen
```

Status-only reports earn no follow-up budget. A reduction counts only when it yields an executable candidate, closes search space, or changes the next decision. An unresolved claim equivalent in strength to the original target is `BLOCKED`; name the failed premise and new fact required to reopen it.

## Serialize Promotion, Not Exploration

Workers screen cheaply. The coordinator full-checks only plausible survivors, invalidates stale parents, and alone promotes the protected best. Serialize promotion, not exploration.

Require independent review for a claimed proof or counterexample, a changed contract assumption, or a high-risk winner. Routine executable candidates do not wait for a second agent.

## Reallocate By Yield

After each concrete return, merge duplicates and fund the best expected gain or information per cost. Keep one affordable incompatible route alive while evidence can discriminate it. Redirect dry/redundant workers; stop one whose coordination cost exceeds candidate or information yield.

Cross-pollinate only after evidence. Share validated facts, counterexamples, and resource limits; launch a hybrid only when the transfer removes a named blocker.

When Scorebench is active, derive worker history, attempts, budgets, and promotions there and do not mirror them locally. Otherwise keep coordination in active context unless persistence was requested.
